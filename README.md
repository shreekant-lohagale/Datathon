# Datathon Project

Brief description
A datathon project repository containing notebooks, scripts, and data exploration for the competition.

Getting started
- Prerequisites: Python 3.8+, pip
- Recommended virtual environment:
  python -m venv .venv
  .venv\Scripts\activate

Install dependencies
- pip install -r requirements.txt (if present)

Usage
- Put raw data files in the `data/` folder (do not commit large raw data).
- Run analysis notebooks in the `notebooks/` folder or scripts in `src/`.

Project structure (suggested)
- data/           # raw and processed data (add to .gitignore as needed)
- notebooks/      # exploratory notebooks
- src/            # scripts and modules
- requirements.txt
- README.md
